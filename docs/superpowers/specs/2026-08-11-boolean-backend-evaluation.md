# T5.1 评估：自研 NURBS 路径 vs 可选 OCCT 后端

**日期**：2026-08-11  
**范围**：仅评估与书面结论（对应设计任务 T5.1）；**不**实施 OCCT 适配器（T5.2 延期）。  
**关联 ADR**：[ADR 0005](../../architecture/adr/0005-boolean-backend-self-hosted.md)

---

## 1. 现状摘要（评估输入）

| 能力 | 状态 |
|------|------|
| 解析曲面 | 平面 / 球 / 柱（`SurfaceKind`；柱–偏轴球曲线仍有 Unsupported） |
| 布尔特解 | 盒–盒、棱柱–盒、球–盒 Intersect ⅛-ball |
| 通用路径 | `IBooleanEvaluator` + 软失败诊断；宽相 BVH（Median/SAH）+ 解析 `intersect_*` 探测（T4.4.c）；印记/分类/重建未通用接线 |
| 弯曲扩展待办 | T3.7 Sphere−Box、T3.8 Sphere∪Sphere |
| 构建约束 | **默认不链接 OCCT**（TX.1）；接口已可替换后端 |

产品原锁定（设计文档「已锁定决策」）：外部内核只参考 OCCT **理念**，自行实现。

---

## 2. 方案对比

### 方案 A — 继续自研（解析 → 印记/分类 → 再 NURBS）

| 维度 | 说明 |
|------|------|
| 学习目标 | 与仓库定位一致：把布尔流水线阶段自己走通 |
| 工作量 | 高；先补全弯曲/通用印记再谈 NURBS 更稳 |
| 风险 | 数值与拓扑边角需自担；周期长 |
| 构建/许可 | 无 OCCT 依赖；保持小二进制与清晰依赖 DAG |
| 与现状契合 | 已有特解 + BVH + `intersect_*`；扩展点明确 |

### 方案 B — 可选 OCCT 后端（`IBooleanEvaluator` 适配器）

| 维度 | 说明 |
|------|------|
| 学习目标 | 偏「对接工业内核 / 快速出复杂布尔」；弱化自研求交–印记细节 |
| 工作量 | 适配 + 拓扑往返 + 许可/三方构建；短期看似快，集成成本不低 |
| 风险 | 双栈语义漂移；调试跨边界；TX.1 需正式放开 |
| 构建/许可 | LGPL 等合规与打包；CI/本地路径变重 |
| 与现状契合 | 接口预留了替换点，但 Phase 1～4 资产不依赖它 |

### 方案 C — 混合（自研主路径 + 远期可选 OCCT）

保留 `IBooleanEvaluator` 可插拔；**近期只走自研**；若目标改为互通或验收对标，再开 T5.2。与 A 短期相同，留 B 为后路。

---

## 3. 评估结论（T5.1）

1. **近期主路径：方案 A（自研）**，优先补通用布尔缺口（印记/分类、T3.7/T3.8），NURBS 排在解析曲面与通用流水线之后。  
2. **不在本阶段执行 T5.2**（不引入 OCCT 链接）。  
3. **保留方案 C 的后路**：接口层已具备；何时启用 OCCT 需另开决策修订 ADR 0005。

详细决策与后果见 **ADR 0005**。
